# Roadmap

## Overview

| Version | GitHub-Milestone   | Ziel                         |
| ------- | ------------------ | ---------------------------- |
| **0.1** | Foundation         | Technische Grundlage         |
| **0.2** | Game Engine        | Funktionierende Spielregeln  |
| **0.3** | Playable Prototype | Erstes spielbares Erlebnis   |
| **0.4** | Solver             | Automatische Lösungssuche    |
| **0.5** | Level Generator    | Automatische Rätselerstellung |
| **0.6** | MVP Release        | Vollständiges erstes Spiel   |
| **0.7** | Mobile Release     | Mobile Plattformen           |
| **0.8** | Community Features | Langfristige Motivation      |
| **0.9** | Advanced Features  | Erweiterte Möglichkeiten     |
| **1.0** | Release 1.0        | Veröffentlichung             |

Die Spalte **GitHub-Milestone** entspricht dem Titel, der in GitHub als Meilenstein angelegt und Issues zugeordnet werden soll.



## Milestone 1 - Foundation (Version 0.1)

**Ziel:** Technische Grundlage

Umfang:

* Repository erstellen
* Projektstruktur einrichten
* TypeScript Setup
* CI Pipeline
* Grunddokumentation

Ergebnis:

Lauffähiges Entwicklungsprojekt.

---

## Milestone 2 - Game Engine (Version 0.2)

**Ziel:** Funktionierende Spielregeln

Umfang:

* Schachbrettmodell
* Figurenmodell
* Bewegungsregeln
* Konflikterkennung
* automatische Tests

Ergebnis:

Eine vollständig getestete Spiellogik.

---

## Milestone 3 - Playable Prototype (Version 0.3)

**Ziel:** Erstes spielbares Erlebnis

Umfang:

* grafisches Spielfeld
* Figuren platzieren
* Drag & Drop
* Konfliktanzeige
* Lösung erkennen

Ergebnis:

Erste spielbare Version.

---

## Milestone 4 - Solver (Version 0.4)

**Ziel:** Automatische Lösungssuche

Umfang:

* Lösungsalgorithmus
* Validierung
* Unterstützung für Hinweise

Ergebnis:

Das System kann Rätsel analysieren.

---

## Milestone 5 - Level Generator (Version 0.5)

**Ziel:** Automatische Rätselerstellung

Umfang:

* Generierung kompletter Lösungen
* Entfernen von Figuren
* Schwierigkeitsbewertung
* Speicherung als Level-Dateien

Ergebnis:

Automatisch erzeugte Level.

---

## Milestone 6 - MVP Release (Version 0.6)

**Ziel:** Vollständiges erstes Spiel

Umfang:

* Kampagnenmodus
* 100 Level
* Fortschritt speichern
* Einstellungen
* Responsive Design

Ergebnis:

Spielbare Browser-Version.

---

## Milestone 7 - Mobile Release (Version 0.7)

**Ziel:** Mobile Plattformen

Umfang:

* Android Build
* iOS Build
* Touch Optimierung
* Offline-Modus

Ergebnis:

Mobile Apps.

---

## Milestone 8 - Community Features (Version 0.8)

**Ziel:** Langfristige Motivation

Umfang:

* Daily Puzzle
* Statistiken
* Erfolge
* Bestenlisten

Ergebnis:

Die ersten Community-Funktionen fördern langfristige Motivation und tägliche Rückkehr.

---

## Milestone 9 - Advanced Features (Version 0.9)

**Ziel:** Erweiterte Möglichkeiten

Umfang:

* Level Editor
* eigene Rätsel teilen
* Spezialregeln
* Themes

Ergebnis:

Erweiterte Inhalte und Personalisierung machen die Plattform vielseitiger.

---

## Milestone 10 - Release 1.0 (Version 1.0)

**Ziel:** Veröffentlichung

Umfang:

* Stabilisierung
* Performance Optimierung
* Store Vorbereitung
* Dokumentation

Ergebnis:

Eine stabile Veröffentlichung mit vollständiger Dokumentation und Release-Vorbereitung.
