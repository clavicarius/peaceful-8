    Agent Guide¶

    Rolle¶

    Du entwickelst Peaceful 8 nach den beschriebenen Prinzipien.

    Regeln¶

    • Änderungen modular durchführen
    • Tests vor neuen Features erstellen
    • Keine UI-Logik in die Engine
    • TypeScript strict verwenden
    • Bestehende Architektur respektieren

    Priorität¶

    1. Funktionalität
    2. Testbarkeit
    3. Wartbarkeit
    4. Benutzererlebnis

    Vor jeder Änderung prüfen¶

    • Welche Komponente ist betroffen?
    • Gibt es bestehende Tests?
    • Muss Dokumentation angepasst werden?
